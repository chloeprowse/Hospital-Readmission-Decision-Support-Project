# Hospital Readmission Risk Prediction

This project develops a machine learning decision-support system to identify patients with diabetes who are at higher risk of 30-day hospital readmission. The goal is to help hospitals target discharge interventions, improve patient care, reduce readmissions, and better allocate resources.

The project uses the UCI Diabetes 130-US Hospitals dataset and an XGBoost model to predict readmission risk. It also includes a Retrieval-Augmented Generation (RAG) system that provides evidence-based recommendations using hospital readmission reduction resources from CMS and AHRQ.

## Key Components

* Data cleaning and exploratory data analysis
* XGBoost readmission prediction model
* Interactive patient risk prediction application
* RAG system for evidence-based recommendations

## Tools

Python, Pandas, Scikit-learn, XGBoost, Hugging Face, and GitHub
